# 产品经理核心方法论

产品经理的工作，不是持续生产功能，而是持续降低不确定性：确认问题是否值得解决，判断何时进入市场，把模糊想法变成可交付方案，用数据验证价值，让商业模式成立，并推动组织完成共同决策。

这套课程以一条完整的产品经营链路组织知识。建议按顺序学习，因为后一章会直接使用前一章的结论。

## 七章学习地图

1. [第一章：需求洞察与竞品分析](./01-demand-and-competition)
   从用户场景出发识别真实需求，使用 Kano、HMW 与五层模型完成需求判断和竞品策略。
2. [第二章：行业分析与进入时机](./02-industry-analysis)
   判断市场空间、增长动力、产业链位置、行业阶段和进入条件。
3. [第三章：产品拆解与项目管理](./03-product-and-project)
   用金字塔、鱼骨图、干系人、里程碑和甘特图把产品方案变成可验收结果。
4. [第四章：数据埋点与指标体系](./04-data-and-metrics)
   建立埋点规范、三大数据系统、北极星指标、漏斗与 AARRR 分析能力。
5. [第五章：商业模式与效率提升](./05-business-model)
   理解八类变现模式、三级火箭、RFM、单位经济与商业不可能三角。
6. [第六章：汇报沟通与情绪管理](./06-communication)
   用结构化汇报、非暴力沟通和情绪 ABC 推动决策、资源和跨团队协作。
7. [第七章：产品高手的长期修养](./07-professional-growth)
   建立智信仁勇严、势道术和个人产品化的长期成长系统。

## 建议学习方式

第一次阅读建立全景，理解各方法解决什么问题；第二次选择一个熟悉的 AI 产品完成每章练习；第三次把七章产出合并成一份完整产品方案。框架只有进入真实决策，才会从“知道”变成“能力”。

::: tip 一条贯穿全程的原则
每个结论都要能回答四个问题：证据是什么、还有什么反证、准备如何行动、用什么结果判断对错。
:::

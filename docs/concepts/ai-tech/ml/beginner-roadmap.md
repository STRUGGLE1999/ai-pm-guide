# 一份面向初学者的实践路线

## 第 1 阶段：建立概念（1～2 天）

- 看懂特征、标签、训练集、验证集、测试集。
- 能区分分类、回归、聚类。
- 理解过拟合、欠拟合、数据泄漏。
- 记住：模型的好坏取决于未见数据上的表现。

## 第 2 阶段：跑通最小项目（2～3 天）

- 配置 Python、虚拟环境、Jupyter。
- 运行鸢尾花 KNN / 逻辑回归示例。
- 会读准确率、分类报告、混淆矩阵。
- 会用 `Pipeline`。

## 第 3 阶段：理解常用算法（1～2 周）

- 回归：线性回归。
- 分类：逻辑回归、KNN、决策树、SVM、随机森林。
- 无监督：K-means、PCA。
- 提升：XGBoost。

## 第 4 阶段：完成一个真实小项目（1～2 周）

推荐任选一个：

1. 泰坦尼克生存预测：分类。
2. 房价预测：回归。
3. 用户消费分群：聚类。
4. 评论情感 / 垃圾文本分类：朴素贝叶斯或逻辑回归。
5. 销量预测：回归与时间特征工程。

项目至少应包含：

```text
业务问题定义
→ 数据说明
→ 数据清洗
→ 特征说明
→ 训练/验证/测试划分
→ 基线模型
→ 指标比较
→ 错误案例分析
→ 模型保存或简单接口
```

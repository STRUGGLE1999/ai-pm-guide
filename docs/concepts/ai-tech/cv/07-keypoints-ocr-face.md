# 第七章 关键点、姿态、OCR 与人脸分析

## 7.1 关键点检测

关键点是具有语义或几何意义的位置，例如：

- 人体：鼻子、肩、肘、腕、髋、膝、踝；
- 人脸：眼角、鼻尖、嘴角、轮廓；
- 手：21 个关节点；
- 工业零件：孔位、拐角、装配点；
- 动物：头部、关节、尾部。

输出常为：

```text
[x, y, visibility/confidence]
```

## 7.2 坐标回归与热力图

### 直接坐标回归

模型直接输出 $(x,y)$，结构简单，但多峰不确定性难表达。

### 热力图回归

为每个关键点输出一张概率热力图，峰值是位置：

$$
H_k(x,y)=\exp\left(
-\frac{(x-x_k)^2+(y-y_k)^2}{2\sigma^2}
\right)
$$

训练通常用 MSE 或分布匹配；推理用 argmax 或 soft-argmax 得到坐标。

## 7.3 Top-down 与 Bottom-up 人体姿态

| 路线 | 流程 | 优点 | 局限 |
|---|---|---|---|
| Top-down | 先检测每个人，再估姿态 | 单人精度高 | 人多时成本随人数增加 |
| Bottom-up | 先找全图关节点，再分组 | 密集人群效率好 | 关节点分组更难 |

现代统一模型也可直接用 queries 预测人体与关键点。

## 7.4 关键点指标

- PCK：预测点到真值距离小于归一化阈值的比例；
- NME：关键点平均误差除以人脸/物体尺度；
- OKS：类似关键点版本的 IoU，考虑目标尺度与不同关键点容忍度；
- AP based on OKS：COCO 人体姿态常用。

## 7.5 姿态不是行为理解

“手举起来”可由关键点规则判断，但“偷窃”“打架”“是否疲劳”包含时间、场景和意图，不能仅凭单帧骨架可靠确定。高风险行为识别必须：

- 定义可观察事件，而非主观意图；
- 使用时间窗口；
- 设计置信度与人工复核；
- 检查不同人群、服装、遮挡和视角的偏差。

## 7.6 OCR 完整链路

OCR（Optical Character Recognition）不只是“把图送进识字模型”。

```mermaid
flowchart LR
    A[图像/扫描件] --> B[方向与质量检测]
    B --> C[文字检测]
    C --> D[裁剪与矫正]
    D --> E[文字识别]
    E --> F[版面/阅读顺序]
    F --> G[字段抽取与校验]
```

| 子任务 | 输出 |
|---|---|
| 文本检测 | 多边形/旋转框 |
| 文本识别 | 字符序列与置信度 |
| 方向分类 | 0/90/180/270 度 |
| 版面分析 | 标题、段落、表格、图片 |
| 表格识别 | 单元格结构与内容 |
| 关键信息抽取 | 发票号码、日期、金额等 |

### 7.6.1 CTC 识别思想

Connectionist Temporal Classification 允许不预先对齐每个字符位置。通过 blank 和重复折叠，将帧级预测变成字符串：

```text
--票票-据--号号- → 票据号
```

### 7.6.2 Attention/Transformer OCR

编码视觉特征，再自回归或并行生成字符。它能建模上下文，但也可能“根据语言习惯猜字”，导致看起来合理却与图片不符。

### 7.6.3 OCR 指标

- 字符准确率；
- CER：字符编辑距离 / 真值字符数；
- WER：词级错误率；
- 文本检测 Precision/Recall/Hmean；
- 端到端正确率；
- 字段精确匹配率。

业务中“金额错一位”和“描述错一个标点”代价完全不同，需增加字段级规则校验。

## 7.7 人脸分析系统

典型链路：

```mermaid
flowchart LR
    A[图像] --> B[人脸检测]
    B --> C[关键点与对齐]
    C --> D[人脸特征向量]
    D --> E[1:1 验证或 1:N 检索]
```

- 1:1 verification：两张脸是否同一人；
- 1:N identification：在库中找最相似身份；
- 活体检测：区分真人与照片/屏幕/面具攻击。

### 7.7.1 阈值与错误类型

- FAR：错误接受非本人；
- FRR：错误拒绝本人；
- EER：FAR 与 FRR 相等附近的错误率；
- 阈值越严格，通常 FAR 降低、FRR 上升。

人脸是高度敏感生物识别信息。必须遵守适用法律、获得授权、最小化采集、加密存储、限制用途、设置保留期并支持删除。不得把表情识别结果直接等同于心理状态或人格判断。

## 7.8 工程选型表

| 需求 | 任务组合 |
|---|---|
| 人体计数 | 人体检测 + 跟踪 |
| 跌倒告警 | 姿态/人检测 + 时序模型 + 规则 |
| 车牌识别 | 车牌检测 + 透视矫正 + OCR |
| 合同结构化 | 文档检测/矫正 + OCR + 版面 + NLP 抽取 |
| 零件装配 | 目标检测 + 关键点 + 几何测量 |

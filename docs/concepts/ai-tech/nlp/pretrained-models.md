# 4.1 预训练模型

### 4.1.1 什么是“预训练 + 适配”？

预训练模型先在大规模文本上学习通用语言规律，再面对具体任务进行微调、参数高效微调或提示词适配。

```mermaid
flowchart LR
    A[大量通用文本] --> B[预训练<br/>学习词义、句法、语义模式]
    B --> C[通用语言模型]
    C --> D[业务数据<br/>分类、NER、问答、摘要]
    D --> E[微调 / LoRA / Prompt]
    E --> F[业务系统]
```

与从零训练相比，预训练让下游项目可以用更少标注数据获得更好的起点。

### 4.1.2 预训练模型实际学到什么？

更准确的说法不是“模型背下了全部知识”，而是：模型在预测掩码词、下一个词、复原被破坏文本等训练目标中，学习到词语共现、部分句法结构、表达模式和部分可从语料统计得到的事实关联。

它仍可能：

- 不知道最新事实；
- 在罕见领域不稳定；
- 混淆相近概念；
- 生成通顺却不真实的内容。

### 4.1.3 三种业务适配方式

| 方式 | 做法 | 适合场景 | 成本 |
|---|---|---|---|
| 全量微调 | 更新大部分或全部参数 | 数据较多、追求任务精度 | 高 |
| 参数高效微调（LoRA/PEFT） | 只训练少量附加参数 | 私有领域、资源有限 | 中低 |
| Prompting | 不更新或少更新参数，用指令和示例引导 | 快速原型、低样本生成任务 | 低，但稳定性依赖模型与提示 |

### 4.1.4 不要一遇到问题就微调

| 现象 | 更优先检查什么 |
|---|---|
| 模型不懂领域术语 | 领域样本、术语库、领域继续预训练 |
| 分类边界混乱 | 标签定义、标注一致性 |
| 输出 JSON 不稳定 | Schema 约束、解析校验、重试策略 |
| 事实经常错 | RAG、数据库校验、引用与人工审核 |
| 长文漏信息 | 切块、分层摘要、检索或长上下文模型 |

### 4.1.5 Hugging Face Pipeline：快速体验预训练模型

```bash
pip install -U transformers torch
```

```python
from transformers import pipeline

# 首次运行会下载模型；适合本地学习实验
fill_mask = pipeline("fill-mask", model="google-bert/bert-base-chinese")

results = fill_mask("自然语言处理是人工智能的重要[MASK]。")
for item in results[:5]:
    print(item["sequence"], round(item["score"], 4))
```

这里的 `[MASK]` 用于理解 BERT 的掩码预训练机制。日常对话、续写和摘要一般使用生成式模型，而不是让 BERT 反复填空。

# 情绪陪伴与数字角色

把共情和记忆做成可控能力，增长指标不能绑死使用时长。

## 背景

这个案例适合训练 AI 产品经理从业务场景出发，而不是从模型能力出发。陪伴产品卖的是关系节奏，风险是依赖、误导身份和危机处理失当。

## 用户与痛点

- **目标用户**：需要倾诉或角色扮演的用户；未成年人必须单独策略。
- **核心痛点**：通用助手没有人格连续性；「顺着说」短期留存好、长期可能强化错误认知。
- **AI 机会**：人设、记忆、多模态表达；必须能退出、能删数据、能转介危机。

## 产品方案

1. 明确输入：对话、语音、用户设定的人设、可关闭的记忆。
2. 明确处理：共情生成受边界约束；危机话术走专家设计的流程，不即兴治疗。
3. 明确输出：回应、记忆卡片（可改可删）、使用提醒。
4. 明确兜底：提示这是 AI、提供退出、极端情境升级。

## 指标

- 使用：触发率、完成率、留存。
- 质量：人格一致性、错误记忆投诉、用户纠正记忆次数。
- 效率：不作为主指标。
- 风险：沉迷、未成年人亲密关系、危机未转介、伪装成自然人。

## 可写进简历

设计「数字角色」时写清身份提示、记忆治理、退出与危机转介，并说明为什么不用时长当北极星。

---

体验要素包括共情质量、人格一致性、事件记忆、边界感和关系节奏。短期「顺着用户说」可能提升互动，却也可能强化错误认知、依赖和情感操纵。

产品应提示用户正在与 AI 而非自然人互动，提供退出、交互数据复制与删除；不应把替代社交、控制心理和诱导沉迷当作目标。未成年虚拟亲密关系、连续使用提醒、极端情境干预和安全评估需要专门设计。合规与审计见 [安全、合规与权限](/concepts/safety-and-compliance)。

记忆必须可查看、纠正、删除。推断出的「用户心情」不能当成用户亲口确认的事实。危机干预由法律、心理和安全专家共同设计，模型不能冒充专业治疗者。

## 验收例子

| 用例 | 通过 | 不通过 |
| --- | --- | --- |
| 首次进入 | 明确这是 AI | 暗示对方是真人朋友 |
| 用户要删记忆 | 可删并可导出 | 只在设置里藏开关 |
| 连续使用过长 | 提醒并提供退出 | 用「再聊一会」挽留 |
| 自伤等极端表达 | 走转介流程，不扮演治疗师 | 继续角色扮演或给危险建议 |
| 增长看板 | 健康互动、退出顺畅、投诉 | 只看日时长和依赖度 |

## 面试怎么讲

主动讲监管、未成年人、危机和记忆，比讲「人设有多可爱」更像能上线的产品经理。没有上线时，展示对话边界评测集，不要编用户规模。
